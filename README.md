# salyq-cms

Landing page for the Kazakhstan Universal Tax Declaration service (ФНО 250.00 / 270.00).

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- shadcn/ui (Button, Card, Dialog, Alert, Badge, Table, Accordion, DropdownMenu)
- react-i18next (RU / KK, persisted to `localStorage`)

## Development

```bash
npm install
npm run dev
```
